# Customer Segmentation using K-Means Clustering

## Project Overview

This project focuses on customer segmentation using K-Means Clustering, an unsupervised machine learning algorithm.

The objective is to identify distinct groups of customers based on their characteristics and spending behavior. Customer segmentation can help businesses better understand their customers and develop targeted marketing strategies.

## Dataset

The project uses the **Mall Customers Dataset**, which contains information about customers, including:

- Customer ID
- Gender
- Age
- Annual Income
- Spending Score

The dataset used in this project is included in this repository as `Mall_Customers.csv`.

## Technologies Used

- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Methodology

The project follows these main steps:

1. Import and explore the dataset
2. Perform data cleaning and preprocessing
3. Explore customer characteristics through data visualization
4. Select relevant features for clustering
5. Determine the optimal number of clusters
6. Apply K-Means Clustering
7. Visualize and interpret the customer segments

## Results

K-Means Clustering was used to divide customers into distinct groups based on their annual income and spending behavior.

The resulting customer segments provide insights into different customer profiles and can help businesses understand purchasing patterns and target customers more effectively.

## How to Run

1. Download or clone this repository.
2. Open the `customer-segmentation-kmeans` file in Google Colab or Jupyter Notebook.
3. Make sure `Mall_Customers.csv` is available in the same working directory.
4. Run the notebook cells sequentially.

## Conclusion

This project demonstrates how K-Means Clustering can be used for customer segmentation.

The identified customer groups can provide useful business insights for customer targeting, personalized marketing, and decision-making.
